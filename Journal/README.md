# Interpretive Journal — pointer

The Journal is a **companion, not a ledger**. It lives in a separate venue, explicitly labelled as
exploration, and borrows none of the ledgers' authority.

Its rule (from `../ARCHITECTURE.md`): *an interpretive artifact may orient attention before supplying
explanation, provided it stays transparent about doing so and never substitutes orientation for evidence.*
Its one evaluation question: *does this orient attention honestly without replacing evidence?*

Nothing in this directory is citable by Ledgers A–D.
